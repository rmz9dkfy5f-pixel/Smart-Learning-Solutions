# Starter Context and Evaluation Loop

Define the behavior and failure hypothesis, select representative cases, record prompt/model/tool
versions, run evaluations, preserve first failures and retries, compare results, and update the
failure log. Claims require evidence. Never promote a prompt with unresolved blocking failures or
invent current model availability.
