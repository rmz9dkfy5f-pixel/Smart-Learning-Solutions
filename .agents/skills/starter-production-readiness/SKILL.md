# Starter Production Readiness

Read the active profile, capabilities, risk register, validation contract, release gate, rollback
plan, and latest evidence. Run `validate --release` and the strongest authorized quality checks.
Report functionality, quality, security, compatibility, operations, blockers, waivers, and
evidence links. A waiver needs approver, reason, review date, compensating control, and evidence.

This skill writes reports only when explicitly authorized. It never deploys.
