# Starter Release Evidence

Require the release-metadata module, canonical version agreement, release-mode semantic
validation, quality evidence, compatibility declaration, migration notes, artifact checksums,
rollback guide, and approver. Preserve failures and missing verification. A PASS claim must link
to actual evidence. Publishing, tagging, pushing, merging, and deployment are separate actions.
