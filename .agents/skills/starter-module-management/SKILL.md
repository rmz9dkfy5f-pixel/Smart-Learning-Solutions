# Starter Module Management

List modules, confirm applicability, dependencies, conflicts, files, permissions, evidence, and
uninstall behavior. Review `module plan`; never infer enablement from a recommendation. Apply with
the exact plan ID, then validate. Disable only checksum-identical module-owned files; preserve
modified and project-owned content for an explicit decision.
